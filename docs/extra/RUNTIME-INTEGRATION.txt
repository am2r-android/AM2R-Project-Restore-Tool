Controller keys
In android/runner/ProjectFiles/src/main/java/YYAndroidPackageDomain/
YYAndroidPackageCompany/YYAndroidPackageProduct/RunnerActivity.java, locate
dispatchKeyEvent. Insert runtime-controller-keys.java.inc immediately after
the existing Gamepad.handleKeyEvent(event) call, before fallback dispatch.
Insert it only once.

The original runner already feeds the key into gamepad state. The added block
consumes gamepad/joystick keys after that, so Android's fallback mapping cannot
turn controller B into a system Back action. System volume keys remain usable.
This is a key-dispatch correction, not an input-device discovery replacement.
The snippet is the added port implementation; the runner source is not bundled.

Android extensions
Verify the generated build includes the Java source from each extension.
On case-sensitive filesystems the generated cache may look for a lowercase
android directory while using Android. Check that both resolve to the same
generated directory if extension sources are missing. Do not ship that cache.
